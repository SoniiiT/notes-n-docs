# 🐧 LXC-LXD Index

> [!ABSTRACT]
> LXC und LXD sind Linux-Systemcontainer-Technologien von Canonical (LXD) und der Linux-Containers-Community (LXC, Incus). Sie bieten eine vollständige Linux-Umgebung in einem leichtgewichtigen Container — keine vollständige VM, aber mehr als ein Anwendungscontainer.
